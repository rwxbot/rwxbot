## 👋 你好，我是 rwxbot

资深全栈 / 后端框架工程师，坐标**北京**，长期活跃于开源组织 [@webfault](https://github.com/webfault)（WebFault）。
12 年码龄，持续在做两件事：

1. **为多语言世界构建一套"同源理念、各自落地"的现代化应用框架家族**（也就是下面的 `*fault` 矩阵）；
2. **把大厂面试与工程实战体系化输出**，帮助更多开发者打通"会用 → 懂原理 → 能面试"的链路。

> **一句话定位**：用统一的架构哲学（IoC + 模块化 + 开箱即用的生产级中间件），把同一套工程方法论，在 TypeScript / Node.js / Go / Python / Java / 区块链上逐一落地。

## 🧩 The `*fault` Framework Family（框架家族）

设计哲学一致 —— **IoC 容器 + 模块化内核 + 零冗余或零依赖的核心**，再按语言特性做最贴合的落地。

| 框架 | 语言 | 定位 | 规模亮点 |
| --- | --- | --- | --- |
| [🟦 upfault](https://github.com/rwxbot/upfault) | TypeScript | 高性能全栈响应式框架：`AeroDiff` O(n) Diff 算法、细粒度响应式、SSR 流式水合 | 10 个独立 npm 包，Tree-shaking 友好 |
| [🟦 nofault](https://github.com/rwxbot/nofault) | Node.js / TS | Java 风格 IoC 微服务框架：限流 / 熔断 / 舱壁、链路追踪、Prometheus、JWT / RBAC、RPC / SSE、MCP 服务器模式 | 18 个包，**核心零依赖** |
| [🟩 gofault](https://github.com/rwxbot/gofault) | Go | Go 模块化后端框架：构造器注入、可组合中间件链、统一异常过滤与优雅关闭 | 内置 18 个中间件；集成 GORM / Redis / gRPC / WebSocket / Prometheus |
| [🐍 pyfault](https://github.com/rwxbot/pyfault) | Python | Python Web 框架：DI 容器 + 装饰器 + 插件机制 | 扩展 AI / 边缘计算 / 多租户 / 合规评估 / 企业级模块，支持 OpenAPI |
| [☕ jvfault](https://github.com/rwxbot/jvfault) | Java | 现代模块化 Java 框架：**零 Spring / Kotlin 依赖**，JDK 8 基线 | 38 个模块 / 269 测试 / 38 个 MR-JAR 双向兼容 Java 8 与 9+ |
| [⛓️ chfault](https://github.com/rwxbot/chfault) | Go | 确定性、可验证的联盟链 BFT 引擎：Tendermint 共识 + BLS 聚合签名 + eth RPC 兼容 | **578 万状态 TLA+ 形式化验证**，零数据竞争 |
